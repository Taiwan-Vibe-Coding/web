穩得 AI 課程 · Session 2

遠端 MCP 操作指南

先連線驗收，再開始 AI＋ERP 練習

這份指南的對象：參加課程、要使用公司已提供 MCP 的學員。

不包含：MCP 伺服器開發、ERP 程式修改，或自行建立公司系統串接。

安全原則：一人一張設定卡、一人一個 Bearer；不轉傳、不截圖、不互換。

一、MCP 需要自己寫程式嗎？

情境你要做的事是否寫程式
上課查自己的示範資料、預覽請假把設定卡提供的課堂 MCP 加到 ChatGPT Work，依指示操作不需要
公司想連既有 ERP、網站或軟體由 MIS／技術人員評估權限、資料範圍、稽核與串接方式；可採既有服務或開發 MCP可能需要，屬系統導入工作

本課的目標是第一列：學會安全使用既有工具，不是要求每位學員變成程式設計師。

二、課前確認（遠端）

  1. 使用自己的 ChatGPT Work 帳號與可連外的電腦；準備瀏覽器或桌面 App。
  2. 向講師／課務取得專屬設定卡。若你只有 PDF 教材、沒有設定卡，請先回報；不要猜 URL、不要使用 127.0.0.1、也不要借同學的卡。
  3. 確認可以開啟課程教材與 ChatGPT Work。若公司網路限制外連，課前通知講師。

三、設定與連線驗收

  1. ChatGPT Work：Plugins → 齒輪 Manage → MCPs → Add server → Streamable HTTP。
  2. 只依自己的設定卡填入名稱、URL（須含 /mcp）及 Authorization: Bearer …；儲存並開啟該 MCP。
  3. 開一個全新任務，輸入：
請用 platform_health 查系統健康狀態。

驗收成功時，應顯示服務正常，且示範員工代碼與你的設定卡一致。不要把回應全文、設定卡或 Bearer 貼到群組。

四、未連線時怎麼做

情況先做什麼不要做什麼
沒有設定卡向課務索取專屬設定卡；先閱讀本頁第一節與 Session 2 的任務說明猜測 URL、沿用 PDF 內舊範例、借用他人 Bearer
設定後看不到工具檢查 MCP 是否開啟、URL 是否含 /mcp、是否重開新任務；回報講師切換到本機 STDIO 或自行安裝未知 MCP
網路或服務中斷改做 mock 練習：先寫出「我想查今年請假紀錄」與「我想申請下週年假，先預覽」兩個問法，並列出預覽時要核對的日期、假別與天數把無法連線當成已完成寫入，或跳過 preview → confirm

五、完成後再進行正式練習

  1. 先查「我的資料」，確認資料範圍與設定卡一致。
  2. 需要寫入時，先要求 preview。
  3. 核對日期、對象、類型與數量後，才明確 confirm。
