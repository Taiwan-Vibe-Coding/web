Day 3 · Session 3 · 共同練習

不連 MCP，也能用 Codex 完成日常工作

整理、比較、改寫、規劃，以及人工確認

這份練習不需要：MCP、設定卡、Bearer 或 ERP 連線。

這份練習需要：一小段你願意用於練習的文字；若是公司資料，請先去識別化。

共同原則：Codex 可以先產出草稿，但不會替你承擔確認責任；有不確定處要標示「待確認」。

練習一：雜亂訊息變成可執行待辦

貼上一段已去識別化的會議筆記、工作訊息或自己寫的情境，輸入：

請協助我整理以下內容。
輸出成表格，欄位為：重點、待辦事項、負責人、期限、需要確認處。
資料沒有明確寫出時，請標示「待確認」，不要自行猜測。

[貼上內容]

檢查：Codex 有沒有把推測當成事實？期限和負責人是否真的來自原文？

練習二：同一件事，三種溝通語氣

選一個日常情境，例如催件、會議通知、請同事補資料，輸入：

請將以下需求改寫成 Email，提供三個版本：
1. 正式；2. 親切合作；3. 最精簡。
每個版本都要包含主旨、收件者要做的事、期限與下一步。
不確定的資訊請以 [待確認] 標示。

[貼上需求]

檢查：哪一版最符合對象？語氣變了，但事實、期限與責任是否一致？

練習三：兩段內容的差異與風險

選兩段已去識別化的規格、公告、SOP 或自己編寫的範例，輸入：

請比較以下 A、B 兩段內容，輸出表格：
比較面向、A 的內容、B 的內容、差異、可能影響、需要人工確認處。
只能根據原文比較；原文沒有的資訊請標示「無法判斷」。

A：
[貼上內容]

B：
[貼上內容]

檢查：「可能影響」是否是合理提醒，而不是被說成既定事實？

練習四：我的今日工作排序

將今天或本週的工作事項去識別化後貼上，輸入：

請將下列工作事項整理成今日行動清單。
依「急迫性、影響程度、可否在 30 分鐘內完成」排序，
輸出：優先順序、下一個具體動作、預估時間、需要誰確認。
不要自行替我承諾期限或替我決定權限事項。

[貼上事項]

檢查：排序是否符合你的實際工作？最後決定仍由你做。

收束：不連 MCP 與連 MCP 的差別

情境Codex 處理什麼你要特別確認什麼
不連 MCP你提供的文字、文件與已授權資料內容是否正確、是否有自行推測、資料是否可提供
連 MCP依權限連接外部系統的資料或工具資料範圍、身分權限、預覽內容與是否確認送出
