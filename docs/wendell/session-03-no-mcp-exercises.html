Day 3 · Session 3 · 共同練習

不連 MCP，也能用 Codex 完成日常工作

整理、比較、改寫、規劃，以及人工確認

這份練習不需要：MCP、設定卡、Bearer 或 ERP 連線。

這份練習需要：一小段你願意用於練習的文字；若是公司資料，請先去識別化。

共同原則：Codex 可以先產出草稿，但不會替你承擔確認責任；有不確定處要標示「待確認」。

沒有自己的練習素材？請使用 本堂示範資料。所有內容均為虛構情境，不含真實客戶、員工或公司機密。

先認識：ChatGPT Work／Codex 可以做什麼？

同一個 ChatGPT 帳號中，適合依工作型態選工具。畫面名稱、可用功能與位置會因帳號方案、公司工作區與管理員設定而不同；以下以課堂常見操作為例。

快速問題

Chat

適合即問即答、腦力激盪、改一段文字或確認一個觀念。

例：「把這段公告改成 100 字內、口氣親切的版本。」

多步驟任務

Work

適合整理資料、研究、產出文件、表格、簡報或報告等有明確成果的工作。

例：「依附件會議筆記，做一份待辦表和一封會後追蹤信。」

技術工作

Codex

適合處理程式、資料夾、專案檔與技術驗證；不必是工程師才可提出需求，但涉及檔案或程式時要先說明範圍。

例：「檢查這個資料夾的檔名是否一致，先列出建議，不要直接改檔。」

畫面位置示意

這是課堂用的介面示意，不是個人帳號截圖；實際位置可能因版本不同而略有差異。

ChatGPT ＋ 新對話 ▣ Projects ⌁ Plugins
ChatWorkCodex
選擇既有 Project，或開新對話
輸入目標 → 加入檔案／背景 → 指定成果格式 → 檢查結果

從桌面 App 開始：三步驟

  1. 在左上角先選 ChatGPT 或 Codex；在 ChatGPT 頁面中，再由上方切換 Chat／Work。
  2. 選擇既有 Project 或開新對話，清楚說明目標、可用素材、限制與驗收方式。
  3. 先檢查結果，再在同一對話中要求修改。需要本機檔案時，只開放這次任務真正需要的資料夾或檔案。
資料位置可做的事重要提醒
Cloud Work（網頁／手機／桌面）在不同裝置續接同一個 Work 對話；用 Project 保存相關內容。以帳號、方案與工作區權限為準。
桌面 App 的本機資料夾在允許時，讓 Work 或 Codex 使用你明確授權的本機檔案。只授權任務需要的範圍；本機檔案與輸出預設留在該電腦，除非你自行分享或移動。
Voice（選用）以語音交辦 Work 或 Codex 任務，並在過程中自然插話修正。需帳號支援並允許麥克風；有些情境還需要螢幕／音訊或輔助使用權限。

四個今天就能用的小功能

功能適合做什麼示範操作
Projects把同一件持續性工作需要的聊天、檔案與指示放在一起。建立「我的每週工作」Project，加入一份去識別化範例與指示：「所有輸出都要標示待確認處。」
檔案與文字整理將你明確提供、且已授權使用的資料整理成摘要、表格、比較表或初稿。加入一段會議筆記，要求「先列待辦，再列缺少資訊；不要自行補寫。」
Work 成果任務一次交辦有多個步驟、有具體交付物的任務。切到 Work，輸入「依下面素材產出一頁會議摘要、待辦表與 Email 草稿；先給我大綱確認。」
Plugins／Apps在公司允許且已連線時，使用外部服務或資料來源。Plugins 是把 Skills、Apps 或 App templates 打包的工作能力；先查看資料範圍與動作權限，再決定是否連接。

  4. 檢查內容後，再要求修正；不要把初稿直接當成定案。

Plugins／Apps：連接前先看清楚

Plugin 不等於自動取得公司資料。它可能只包含操作指引（Skills），也可能需要 Apps 才能連到外部資料或執行動作。即使 ChatGPT 中看得到某個 Plugin，是否能安裝、是否能連接 App、是否能執行寫入，仍取決於方案、工作區、角色與來源系統本身的權限。

  1. 從 Plugins 或 Settings → Plugins 找到要用的能力，先看它包含的 Apps、所需設定與隱私政策。
  2. 只有在公司允許時才按 Connect；若需要，完成 OAuth 與同步設定。
  3. 連接後，以 @ 提及 App，或在輸入框按 ＋ → More 選擇 App。
  4. 第一次先用低風險、唯讀的問題測試；若是建立、修改或傳送資料的動作，先確認是否需要人工確認。

課堂原則：看得到 Plugin 不代表有權使用資料；連上 App 也不會越過原系統權限。公司資料的 Plugin／App 由 MIS 或工作區管理員確認資料範圍、唯讀／寫入權限與核准流程後再使用。

功能說明參考 OpenAI 的 ChatGPT Work and Codex 與 Plugins in ChatGPT and Codex；可用功能仍以個人帳號與公司工作區設定為準。課堂保留介面示意而未放固定截圖，因實際介面與權限會因帳號而異。

檢查：Codex 有沒有把推測當成事實？期限和負責人是否真的來自原文？

練習二：同一件事，三種溝通語氣

選一個日常情境，例如催件、會議通知、請同事補資料；沒有素材時可使用示範資料二。輸入：

請將以下需求改寫成 Email，提供三個版本：
1. 正式；2. 親切合作；3. 最精簡。
每個版本都要包含主旨、收件者要做的事、期限與下一步。
不確定的資訊請以 [待確認] 標示。

[貼上需求]

檢查：哪一版最符合對象？語氣變了，但事實、期限與責任是否一致？

小結：不連 MCP 與連 MCP 的差別

情境Codex 處理什麼你要特別確認什麼
不連 MCP你提供的文字、文件與已授權資料內容是否正確、是否有自行推測、資料是否可提供
連 MCP依權限連接外部系統的資料或工具資料範圍、身分權限、預覽內容與是否確認送出
