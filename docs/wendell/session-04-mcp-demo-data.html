STDIO MCP 練習：設備借用資料

全部為虛構資料，僅供本機唯讀 MCP 練習

請在新建的練習資料夾中，以 equipment-loans.json 為檔名建立資料檔。不得加入真實姓名、設備序號、公司內部位置或帳密。

{
  "equipment": [
    {"id":"EQ-001","name":"頻譜分析儀練習機","status":"borrowed","borrower_code":"DEMO-A01","due_date":"2026-08-03","note":"配件清單待確認"},
    {"id":"EQ-002","name":"傳導干擾測試治具","status":"available","borrower_code":null,"due_date":null,"note":""},
    {"id":"EQ-003","name":"校正用訊號產生器","status":"borrowed","borrower_code":"DEMO-B02","due_date":"2026-07-30","note":"歸還時間未確認"},
    {"id":"EQ-004","name":"靜電放電測試槍練習機","status":"maintenance","borrower_code":null,"due_date":null,"note":"維護完成日待確認"}
  ]
}

資料閱讀規則

  • status 為 borrowed 才是目前借用中。
  • due_date 為空，不可自行推算歸還日。
  • note 有「待確認」時，工具輸出應保留這件事。
  • 設備不存在時，應回覆找不到資料，不可產生虛構紀錄。
